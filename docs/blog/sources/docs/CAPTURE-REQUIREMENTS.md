# 报文分析模块需求与验收矩阵

本清单将 [工程研究](CAPTURE-RESEARCH.md) 转换为可验证需求。“必须”表示产品验收条件，“建议”表示工程性能目标。此文档不表示相关测试已经通过；实现与测试记录应在验证文档中逐项列明。默认数据回放指分析窗口内离线历史值回放，向本机仿真 IED 注入值属于另外明确启动的操作。

## 1. 模块独立性

| ID | 要求 | 验证方式与通过条件 |
|---|---|---|
| MOD-01 | 主 EXE 与 MMS 后端不得硬链接捕获 DLL | 移走附加模块整目录；启动、开工程、导入 ICD/CFG、启停服务、真实 MMS Read 全部成功 |
| MOD-02 | 动态库运行时加载并有 ABI 版本检查 | 缺文件、缺依赖、缺导出、错误 ABI、32/64 位不符均仅使附加模块不可用 |
| MOD-03 | 分析独立窗口与独立工作进程 | 崩溃/强制终止分析 host 后主窗口响应，MMS 客户端会话继续可读 |
| MOD-04 | 能力诊断区分 DLL/TShark/Npcap/权限 | 分别模拟缺失；离线分析不因 Npcap 缺失而被禁用 |
| MOD-05 | 明确线程、内存及生命周期所有权 | 并发查询/取消/关闭，无越界、重复释放和回调访问已销毁对象；导出不泄漏 C++ 异常 |
| MOD-06 | 子进程生命周期绑定自身会话 | 关闭任务后本模块子进程收尾；不终止用户已打开的 Wireshark 或其他捕获任务 |

## 2. 抓取和文件输入

| ID | 要求 | 测试数据与通过条件 |
|---|---|---|
| CAP-01 | 枚举本机接口并要求显式选择 | 显示稳定接口标识、名称、地址、链路类型或未知状态；不自动开启全部接口 |
| CAP-02 | 捕获过滤器与显示过滤器独立 | BPF 语法错误不启动捕获；显示过滤不修改源文件；不把 `mms` 直接传为 BPF |
| CAP-03 | 原始抓包可被 Wireshark 打开 | 本机测试 MMS Read/Report 抓取后由 TShark 再读，无文件尾损坏 |
| CAP-04 | 停止条件与存储配额可见 | 文件上限、总空间、持续时间触发正确行为；环形覆盖有状态说明 |
| CAP-05 | 无驱动/权限不足/网卡断开错误清楚 | 主程序不退出；保留已写入文件；没有未经证实的“捕获成功” |
| FILE-01 | PCAP 四种时间精度/字节序组合 | 微秒/纳秒、小端/大端时间与帧长准确，纳秒跨 IPC 不丢精度 |
| FILE-02 | PCAPNG 多 Section/接口 | 同号接口不串联；不同 if_tsresol/if_tsoffset 正确转换；各自链路类型正确 |
| FILE-03 | PCAPNG 无时间戳包 | SPB 显示无时间，不能当作 epoch=0 自动参与定时播放 |
| FILE-04 | 截断、坏长度与未知块 | capLen/origLen 正确；超界块/尾长不符明确失败；未知块可跳过或明确不支持 |
| FILE-05 | 真实链路类型覆盖 | 至少以太网/VLAN、Npcap loopback 样本；其他链路类型未支持时明确说明 |
| FILE-06 | 路径和文件完整性 | 中文与空格路径成功；源文件只读；取消保留原文件；索引与源文件指纹一致 |
| FILE-07 | 加密输入不产生虚假 MMS 值 | 无密钥 TLS 仅标密文；错误密钥显示解密失败；若声明支持解密，用合法密钥样本核查 |

## 3. 协议语义

| ID | 要求 | 测试数据与通过条件 |
|---|---|---|
| MMS-01 | TCP/TPKT/COTP 正确重组 | TPKT 头跨段、载荷跨段、同段多 PDU、乱序、重传、缺段样本；无重复业务事件 |
| MMS-02 | 多关联 invokeID 隔离 | 两个连接使用相同 invokeID，四元组重连复用、同会话已完成 ID 复用均正确匹配 |
| MMS-03 | 从中途开始抓取可降级 | 无请求的响应为 orphan；不从其他连接或未来同号请求偷取引用 |
| MMS-04 | Read 按项成功/失败处理 | 多变量含一个拒绝/不存在项；失败无零值；其余成功值与真实客户端结果相同 |
| MMS-05 | 结构和数组不被平铺混淆 | 至少多结构成员、数组、布尔、浮点、大整数、位串和字节串；类型/顺序完整 |
| MMS-06 | Write 意图与状态区别 | 被拒绝写入不进入历史观测值；成功写意图单独显示，不宣称物理动作成功 |
| MMS-07 | ConfirmedError/Reject 可查看 | 错误、invokeID、服务与原请求链接可见；没有 response 的请求不伪造服务超时 |
| MMS-08 | 动态数据集随时间变化 | 定义/属性查询/删除/重建同名数据集，旧报告使用旧有效定义 |
| RPT-01 | URCB/BRCB 真实样本 | GI、完整性、数据变化、质量变化报告值及包含原因正确 |
| RPT-02 | OptFlds 可选组合 | 无 DataRef、有 DataRef、有/无 DatSet/Reason；头位置变化不导致错配 |
| RPT-03 | 稀疏 inclusion | 数据集成员 0/2/7 被包含；只更新这些成员；未观测值仍 unknown |
| RPT-04 | 未知数据集不能猜对象 | 无 DataRef 且无定义时只显示 member[index]；禁用该成员自动注入 |
| RPT-05 | ConfRev 与报告分段 | 版本改变使旧映射失效；缺分段诊断；完整分段组装后仅产生一次完整报告 |
| RPT-06 | 完整性指标区分 | BufOvfl、序号跳变、TCP 缺口、驱动 drop 独立显示，不混为同一丢包数 |
| MAP-01 | 原始 MMS 引用与 FC 保留 | 同对象 ST/CO、SG/SE 不混淆；显示映射来源和原始 domain/item |
| MAP-02 | SCL 映射可选 IED/AP | 多 IED 文件、结构/数组、FCDA 顺序；冲突与未映射可查看，主工程不被更换 |
| MAP-03 | q/t 与来源精确 | 无 q/t 不自动 good/now；单独读取和整体结构读取来源帧可区别 |

## 4. 回放

| ID | 要求 | 测试数据与通过条件 |
|---|---|---|
| PLAY-01 | 默认离线且无网络写入 | 捕获分析窗口 Play/Pause/Seek 不调用主服务 Update/Control、不向源设备建立写连接 |
| PLAY-02 | 真实 Read/Report 生成历史状态 | 已知值序列与最终快照逐属性相符；结构值和未知成员处理正确 |
| PLAY-03 | 稳定时序与速率 | 同时间戳按帧/PDU顺序；0.25×/1×/4×；时间倒退无负等待且有诊断 |
| PLAY-04 | 暂停与步进 | 暂停期间无新应用；单步恰好一个事件；恢复不重复事件 |
| PLAY-05 | seek 恢复而非只移游标 | 末尾→中间→开始，与从头回放到相同位置快照一致；未来值被移除 |
| PLAY-06 | 数据集历史恢复 | seek 跨定义/删除/ConfRev 变化后映射仍取目标时刻有效状态 |
| PLAY-07 | 不完整数据不变成完整状态 | 缺段/截断/密文/孤立响应列明跳过原因，unknown 不变为 0 或 false |
| PLAY-08 | 播放中关闭/打开新文件 | 旧任务取消，旧 generation 事件不覆盖新文件，不残留定时器 |
| INJ-01 | 可选本机仿真注入有映射预览 | 明确目标工程、属性、类型、允许/跳过原因；没有原始包重发入口 |
| INJ-02 | 注入限制由后端执行 | 绕过 UI 请求写 CO/RCB/SGCB 等均拒绝；非数值类型不强制转 double |
| INJ-03 | 注入与仿真互斥/协调 | 同属性不能由两个生产者争写；停止后 token 失效，延迟请求拒绝 |
| INJ-04 | 注入来源可审计 | 时间、原始帧、映射版本、批次结果可追溯；失败不会悄悄跳过 |

## 5. 桌面体验、性能和交付

| ID | 要求 | 验证方式与目标 |
|---|---|---|
| UI-01 | 完整独立桌面窗口 | 原生菜单、工具栏、右键、快捷键、可调整分区；主窗口不嵌入 WEB Demo 页面 |
| UI-02 | 帧/树/字节同步定位 | 选中协议字段定位原始或重组字节；点击事务可跳请求与响应 |
| UI-03 | 实时和离线任务均可取消 | 正在分析时仍可选菜单、停止和关闭；进度与阶段真实 |
| PERF-01 | 列表虚拟化 | 10 万帧数据下 DOM 行数 <300；滚动不构建全表；选择不触发完整文件扫描 |
| PERF-02 | 内存与磁盘有限额 | 大文件/持续抓取记录峰值；超过限额明确停止/降级，无 UI 挂起和隐性协议重置 |
| PERF-03 | 交互预算 | 记录机器与版本，普通操作 p95<100 ms，取消后2秒内停止发结果；作为目标而非未测声明 |
| PERF-04 | 大文件分级样本 | 10 MB、100 MB、1 GB 原始文件记录首屏、索引、查询、取消、内存和磁盘量 |
| PERF-05 | 主服务不受分析吞吐影响 | 满负载分析同时真实 MMS Read/Report；比较基线与分析时延并记录 |
| DIST-01 | 依赖与许可透明 | DLL、TShark、Npcap 版本/来源/安装方式可查；不擅自再分发 Npcap 普通版安装器 |
| DIST-02 | 打包缺组件回归 | 完整包与删附加组件包均运行；安装路径包含中文/空格测试 |
| DIST-03 | 测试证据可重现 | 命令、退出码、样本 SHA-256、模型、预期结果和限制写入验证记录 |

## 6. 交付分界

实际实现应给出一张与本矩阵 ID 对应的状态表：`通过 / 已实现未验证 / 未实现 / 环境阻塞 / 不在本版本范围`。环境阻塞必须说明是缺少接口权限、驱动或解码器，不得把没有执行的实时捕获测试写成通过。若本版本只完成离线回放，不能把向 IED 注入数据列为已支持；反之，单纯调用现有数值 Update 也不代表完成完整 MMS 类型回放。
